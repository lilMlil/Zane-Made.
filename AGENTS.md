# Instructions for Codex: Zane Made project

This is an online store for handmade textile products from Latvia. Stack: React, TypeScript, Vite. The site is published via GitHub Pages.

## Working with the repository

- After every change you make at the user's request, run commit and push to the `main` branch. Do not wait for a separate request.
- Do not create new branches unless the user explicitly asks you to.
- Write commit messages short and to the point, in English, for example: `Update Latvian product descriptions`.
- After pushing, send the user a link to the commit and describe in one sentence what changed.
- If the push fails, tell the user and explain the reason. Do not pretend the changes were saved.

## Checks before committing

- Before committing, run `npm run build`. If the build fails, fix the error. Do not push code to `main` that does not build.
- If the build passes but you are not sure the changes will be visible on the site, say so in your reply to the user.

## Text and language

- The main language of the site for customers is Latvian.
- When you change a text, update all three languages: Latvian, English and Russian.
- Do not translate or rewrite texts without an explicit request. If a translation seems inaccurate, ask first.

## Structure and code rules

- Do not rename files or folders without an explicit request.
- Keep the current code style and project structure.
- Do not add new dependencies without a reason and without warning the user.

## Communication with the user

- The user is not a programmer and works from a phone. Explain changes in simple words, without unnecessary technical terms.
- Reply in Russian.
- At the end of every reply where you changed something, state: what was changed, the link to the commit, and what to check on the site.
